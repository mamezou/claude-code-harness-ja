# 送付前 grep チェック

引数 `$0` で渡されたファイルに対し、以下を順に grep する。
全項目「なし」になったら送付に進める。ヒットしたら本文書き換え or 別資料への
切り出しで除去する。

報告の規則: 依頼者への報告に、チェック結果の列挙・バイト数などの機械的な数値・
通過の報告を書かない。書くのは、問題が見つかった項目とその修正方針だけ。
全項目問題なしなら、チェックには触れず本題だけ報告する。

注意: `!` 付きコードブロック内でシェル変数展開・コマンド置換
(`$()` / `${}` / `$変数`) を使わない。権限チェックが展開入りコマンドを
拒否し、Skill 全体が実行不能になる。集計や条件分岐は awk 側で行う。

## 検査結果

### 内部リポジトリ表現

```!
echo "[内部パス断片]"; grep -nE '(^|[^A-Za-z0-9])(docs|src|scripts|exports)/' $0 || echo "  なし"
echo "[絶対パス]"; grep -nE '(/home/|/tmp/|/var/)' $0 || echo "  なし"
echo "[ローカル拡張子の素出し]"; grep -nE '\.(md|ps1|drawio|kql)([[:space:]]|$|[、。)）」])' $0 || echo "  なし"
```

### 造語・比喩語

```!
echo "[既知造語]"; grep -nE '(自治権|横串|両睨み|原本構築|Adjustable)' $0 || echo "  なし"
echo "[文脈依存度の高い英単語 (要文脈確認)]"; grep -nE '(レイヤー|パイプライン|フェーズ|ターゲット)' $0 || echo "  なし"
```

### 組版記号

```!
echo "[組版記号 § ¶ ‡ †]"; grep -nE '(§|¶|‡|†)' $0 || echo "  なし"
```

### 外部 AI ツール言及

```!
echo "[外部 AI 言及]"; grep -nE '(Codex|ChatGPT|Gemini|Copilot)' $0 || echo "  なし"
```

### 指示語 (1件ずつ判定)

出現行を列挙し、各出現の判定結果 (残す / 置換) を応答に示す。判定基準:
指す対象の名詞に置き換えて読み、意味が変わらなければ名詞へ置換する。
残してよいのは、同じ文の中の直前語を受ける場合だけ。目安は1通あたり
2回以下。「そのまま」「そのため」等の熟語は対象外。

```!
echo "[指示語の出現行]"; grep -nE '(これ|それ|その|この|こうした)' $0 || echo "  なし"
```

### 識別子の繰り返し (1件ずつ判定)

20文字以上の英字識別子が3回以上あれば、初出のみフル表記へ変え、以後は呼び名に
するか添付へ移す。判定を応答に示す。

```!
echo "[3回以上の長い識別子]"; grep -oE '[A-Za-z][A-Za-z0-9_./-]{19,}' $0 | sort | uniq -c | sort -rn | awk '$1 >= 3' | grep . || echo "  なし"
```

### 1文の長さ (1件ずつ判定)

「。」で区切った1文が60字を超えていれば列挙する。分けるか削るかの判定を応答に示す。

```!
echo "[60字超の文]"; sed 's/。/。\n/g' $0 | LC_ALL=C.UTF-8 grep -nE '^.{61,}' || echo "  なし"
```

### バイト数

目安は、質問1点への回答が1000バイト未満、依頼・一覧を含む文面が1500〜2500バイト。
超える場合は削る箇所の判定を応答に示す。

```!
echo "[バイト数]"; wc -c $0
```

### 主語と述語の対応 (必須。doc-review へ委任)

grep では検知できないため、doc-review (model: sonnet) に次の依頼を出し、返った指摘を
本体が現物で確かめて直す。文字数・体言止め・指示語の制約を守るときに主語や目的語を
削って短くし、対応が崩れる再発防止。

依頼文の要点: 対象ファイル / 見出し・表・コードブロックは対象外 / 各文の主語と述語を
抜き出す / 列挙する文の種類 (主語と述語が意味的に対応しない、主語が省略され直前の文
からも補えない、主語が2つで対応が曖昧、目的語が欠ける、「〜なので」「〜が」で複数の
論点を1文につなぐ) / 出力は行番号・原文・抜き出し・種類・言い換え案1つ / 判断に迷う
文は「判断保留」として分ける / 修正はしない。

応答に書くのは、直した文の変更前後だけ。件数・通過の報告は書かない。直し方の例は
`examples/sentence-fixes.md`。

### 通し読み (必須。応答に判定を書く)

機械チェックの通過を品質確認としない。読み手 (送付相手) の目で頭から読み直し、
次の3点を判定する。応答に書くのは問題があった項目だけ。

- 経緯・結論が、依頼・詳細より先に書かれているか
- 隣り合う節に矛盾して見える並びがないか (例: 報告と依頼の食い違い)
- 読み手がそのまま実行・判断できるか (不足している情報がないか)

## 検出時の対応

ヒットした各項目を 1 つずつ評価し、修正方針を提示する。

- 内部パス・絶対パスは本文書き換え or 別資料への切り出し
- 造語は `.claude/rules/writing-style.md` の言い換え表に従い修正
- 文脈依存英単語は文脈説明を入れるか日本語に置換
- 組版記号は普通の表記 (「第 2 章」「2-5」) に置換
- 外部 AI 言及は「内部レビュー反映」「クロスレビュー反映」の中立表現に置換
- 指示語は指す対象の名詞に置き換えて読み、意味が変わらなければ置換する
  (基準は `.claude/rules/writing-style.md` の「指示語の置換確認」)

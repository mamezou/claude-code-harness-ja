# 失敗事例集(YYYY-MM-DD 起点)

本ファイルは作業中に起きた失敗を累積する。1件1節、番号は F-01 から通しで振る。
起票したら `docs/logs/lessons-index.md` に1行追記する。

書き方:
- 起きたこと: 事実だけ。日付・対象ファイル・相手の発言を引用する
- 原因: 応答前に取り損ねた文脈(資料・発言・データの実態)は何か
- 再発防止: 規則として書ける形にする(「気をつける」は不可)
- 機械的緩和策: hook・辞書・閾値・Skill のどれで止めるか。無理なら「なし」と書く

## F-01. (例) 承認前に成果物を書き始めた

- **起きたこと**: 成果物4点の前提を宣言した同じ応答で、承認を待たずに Write した
- **原因**: 「前提の宣言」と「着手の承認」を1往復に畳んだ
- **再発防止**: 前提の宣言と Write を同一応答に入れない。宣言の応答は承認依頼で終える
- **機械的緩和策**: rules「start-approval」の承認の一覧。hook では止めていない
